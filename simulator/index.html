How to Use
TAP TEMPO
连续点击 TAP 4–8 次，系统会对最近 8 次间隔取平均值计算 BPM。
点击越均匀，BPM 越准确。

BPM SYNC
开启后，MiniMac 移动速度和 LED 速度会锁定到当前 BPM。
灯光动作与节拍同步，演出时节奏感更强。

CUE SLOTS（1–8）
每个 Slot 可以保存一套完整的场景参数（图案、颜色、灯光、速度等）。
工作流程：
① 在演出前调好每个场景 → 选对应 Slot → Save Cue
② 演出中：选 Slot → Load Cue，场景瞬间切换
③ 切换速度由 Easing 滑块控制

建议场景分配
1 → 开场低能量
2–4 → 中等强度变化
5–7 → 高能量 Drop
8 → Blackout / 结束
